# Programación para Inteligencia Artificial

Repositorio de trabajo de la asignatura de la **Maestría en Inteligencia Artificial de la UADY**. Aquí se concentran apuntes, ejercicios, tareas y el proyecto integrador del curso.

## Propósito de la asignatura

Construir software que valide información, transforme datos y conecte componentes de un sistema de inteligencia artificial. El resultado debe ser código funcional, probado y acompañado por instrucciones suficientes para que otra persona pueda instalarlo y ejecutarlo.

| [Unidad 3](unidades/03-integracion-de-componentes/) | Integración de componentes | Proyecto de integración y orquestación | 20 % |

El acceso directo a los trabajos listos para revisar está en **[ENTREGAS.md](ENTREGAS.md)**.

## Organización del repositorio

```text
.
├── README.md                 # Portada y mapa general
├── ENTREGAS.md               # Índice para revisión del profesor
├── unidades/
│   ├── 01-python-moderno/
│   ├── 02-datos-y-representaciones/
│   └── 03-integracion-de-componentes/
├── proyecto-integrador/      # Avances y entrega final
└── recursos/                 # Referencias y materiales compartidos
```

Cada unidad sigue la misma convención:

- `apuntes/`: notas de clase y conceptos explicados con palabras propias.
- `ejercicios/`: prácticas breves realizadas durante el taller.
- `tareas/`: evidencias evaluables, cada una con instrucciones de ejecución.
- `README.md`: temario, progreso y enlaces importantes de la unidad.

## Forma de trabajo

1. Registrar los conceptos de cada sesión en `apuntes/`.
2. Guardar las prácticas en `ejercicios/` y las entregas calificables en `tareas/`.
3. Documentar en el README de cada trabajo su objetivo, datos de entrada, ejecución y resultado.
4. Actualizar [ENTREGAS.md](ENTREGAS.md) cuando una evidencia esté lista para revisión.
5. Hacer commits pequeños con mensajes que expliquen el cambio.
