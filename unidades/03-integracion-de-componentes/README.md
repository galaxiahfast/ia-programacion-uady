# Unidad 3 · Integración de componentes para sistemas de IA

## Objetivo

Conectar almacenamiento, consultas y componentes de aplicación mediante contratos claros y flujos con estado.

## Temas

- **SQL con Python:** conexión, consultas parametrizadas y persistencia.
- **Neo4j:** entidades y relaciones como grafos, con consultas Cypher.
- **Interfaces:** responsabilidades y contratos entre componentes.
- **Orquestación:** estado, transiciones y manejo de fallos con LangGraph o LangChain.
