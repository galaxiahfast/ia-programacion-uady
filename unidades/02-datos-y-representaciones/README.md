# Unidad 2 · Procesamiento y representación de datos para IA

## Objetivo

Preparar, transformar, representar y explorar datos de forma reproducible para su uso en sistemas de inteligencia artificial.

## Temas

- **NumPy:** arreglos, ejes, operaciones vectorizadas y broadcasting.
- **Pandas y datasets:** limpieza, combinación, datos faltantes y calidad de tablas.
- **Formatos y tensores:** CSV, Parquet e interoperabilidad con tensores de PyTorch.
- **Matplotlib:** gráficas para explorar datos y justificar hallazgos.
