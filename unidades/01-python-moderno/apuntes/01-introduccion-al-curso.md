# Introducción a la asignatura y a Python

## Propósito del curso

La asignatura busca desarrollar software para trabajar con datos: programas que validen información, transformen datos y conecten componentes de un sistema de inteligencia artificial.

El producto no es solamente código que funcione. También debe incluir:

- pruebas;
- instrucciones de instalación y ejecución;
- decisiones explicadas;
- condiciones suficientes para que otra persona pueda usarlo.

El entrenamiento y estudio detallado de modelos se abordará en asignaturas posteriores.

## Recorrido del curso

1. **Python moderno:** fundamentos del lenguaje, contratos de datos y proyectos reproducibles.
2. **Datos y representaciones:** arreglos, tablas, tensores y visualización.
3. **Integración de componentes:** persistencia, consultas desde Python y flujos con estado.
4. **Proyecto integrador:** una solución local que combine lo aprendido y justifique sus decisiones.

## Evaluación

| Evidencia | Valor |
| --- | ---: |
| Unidad 1: ejercicios de Python moderno, validación y calidad | 30 % |
| Unidad 2: proyecto de procesamiento y representación de datos | 30 % |
| Unidad 3: proyecto de integración y orquestación | 20 % |
| Proyecto final: integración, documentación y presentación | 20 % |

## Proyecto integrador

### Primer avance

- Problema acotado.
- Datos con procedencia clara.
- Procesamiento funcional.
- Primera operación SQL ejecutada desde Python.

### Entrega final

- Persistencia.
- Flujo de componentes con estado y fallos visibles.
- Pruebas y documentación.
- Demostración que sustente las decisiones tomadas.

## Forma de trabajo durante el taller

El ciclo de aprendizaje propuesto es:

1. predecir qué hará el código;
2. ejecutarlo;
3. explicar el resultado;
4. modificarlo y observar qué cambia.

Los materiales iniciales mencionados son un cuaderno de fundamentos de Python y otro sobre las 19 reglas del Zen de Python.
