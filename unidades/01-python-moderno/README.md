# Unidad 1 · Programación eficiente en Python para IA

## Objetivo

Dominar las herramientas modernas del lenguaje y establecer proyectos reproducibles, validados y probados.

## Temas

- **Fundamentos:** funciones, colecciones, decisiones, ciclos, excepciones y objetos.
- **Contratos de datos:** anotaciones de tipo y validación con Pydantic.
- **Flujos y recursos:** iteradores, generadores y administradores de contexto.
- **Reproducibilidad y calidad:** proyectos con uv, revisión con Ruff y pruebas con pytest.
